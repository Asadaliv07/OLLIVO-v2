# Ollivo macOS Desktop App — Bug Register

| Bug ID | Severity | Feature / Area | Root Cause | Fix Implemented | Regression Test / Verification | Status |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **BUG-01** | **CRITICAL** | macOS Sandboxing | Missing `com.apple.security.network.client` entitlement key in `DebugProfile.entitlements` and `Release.entitlements`. macOS kernel blocked outgoing sockets (`OS error: Operation not permitted, errno = 1`). | Added `<key>com.apple.security.network.client</key><true/>` to entitlement plists. | Verified live network connection to `http://127.0.0.1:11434/api/version` returning HTTP 200. | **CLOSED** |
| **BUG-02** | **MEDIUM** | Top Bar UI | Unwrapped `Column` in `_buildDesktopTopBar()` caused `RenderFlex overflowed by 178 pixels on the right` when window was resized to smaller widths. | Wrapped title `Column` in `Expanded` widget and added `TextOverflow.ellipsis`. | `flutter analyze` clean; resized desktop window without layout overflow warnings. | **CLOSED** |
| **BUG-03** | **HIGH** | Ollama Daemon | Local Ollama background service was not running on host port `11434`, causing connection refused errors. | Initiated background `ollama serve` process. | Endpoint check `curl -s http://127.0.0.1:11434/api/version` returns `{"version":"0.40.2"}`. | **CLOSED** |
| **BUG-04** | **LOW** | Memory Extraction State | `_recentSavedMemory` state was retained across conversation resets, causing stale memory extraction banners. | Implemented `clearSavedMemoryBanner()` in `ChatController` to reset memory notification state. | Covered by `test/ai_workflow_test.dart` Test 6. | **CLOSED** |
| **BUG-05** | **HIGH** | Daemon Recovery (MOD-002) | No managed background daemon recovery service existed; failure to connect to Ollama left users stranded with raw network exceptions and no recovery path. | Implemented `ProcessService` with multi-path binary discovery, argument-safe detached process invocation, exponential backoff health polling, and terminal fallback instructions. | Covered by `test/process_service_test.dart` (4/4 tests passing). | **CLOSED** |
| **BUG-06** | **HIGH** | Viewport Scrolling (CORE-008) | Chat viewport unconditionally jumped to bottom during token generation, preventing users from reviewing previous message history while streaming was active. | Implemented scroll threshold pin detection (`_isPinnedToBottom`), floating "Scroll to latest" button with unread indicator, and smart auto-follow only when user is near bottom. | Covered by `test/chat_view_test.dart` (2/2 tests passing). | **CLOSED** |
| **BUG-07** | **CRITICAL** | Data Safety (SET-002) | Application lacked backup creation and disaster recovery capabilities; database migration or manual corruption risked total data loss. | Implemented `BackupService` with atomic SQLite transaction snapshots, GZip compression, SHA-256 manifest integrity verification, and pre-restore validation. | Covered by `test/backup_service_test.dart` (4/4 tests passing). | **CLOSED** |
| **BUG-08** | **MEDIUM** | Desktop Integration (MAC-003, UI-004) | Missing native macOS system menus (`NSMenu`) and keyboard shortcuts, violating Apple HIG desktop ergonomics. | Implemented `PlatformMenuBar` with `hasMenu` runtime checks, standard menu categories (App, File, Edit, View, Window, Help), and shortcuts (⌘N, ⌘K, ⌘O, ⌘,, ⌘\, ⌘1-6, Escape). | Covered by `test/widget_test.dart` and `flutter build macos`. | **CLOSED** |
| **BUG-09** | **MEDIUM** | Markdown & Code Highlighting (CORE-001, CORE-003) | Assistant responses were displayed as plain unstyled text; code blocks lacked syntax highlighting and one-click copy buttons. | Implemented `RichMarkdownView`, `CodeBlockWidget`, and `MathBlockWidget` with multi-language token coloring, line counts, and 2s copy feedback. | Covered by `test/markdown_view_test.dart` (4/4 tests passing). | **CLOSED** |
| **BUG-10** | **LOW** | Inference Parameters & System Prompt (CORE-004) | Sampling constraints (context window, top_p, top_k, repeat penalty, system prompt) could not be customized by users. | Extended `SettingsService` and `AIService` to persist, validate, and inject inference parameters into local Ollama request options. | Covered by `test/model_parameters_test.dart` (3/3 tests passing). | **CLOSED** |
