## 2. Table Definitions & Purpose

### 2.1 Table: `conversations`
* **Purpose:** Stores metadata for multi-turn chat sessions with the local Ollama model.
* **Columns:**
  * `id` (`TEXT PRIMARY KEY`): Unique UUIDv4 identifier.
  * `title` (`TEXT NOT NULL`): Auto-generated or user-edited conversation title (e.g., *"Flutter Color Scheme Setup"*).
  * `created_at` (`INTEGER NOT NULL`): Unix epoch timestamp in milliseconds.
  * `updated_at` (`INTEGER NOT NULL`): Unix epoch timestamp of last message.

### 2.2 Table: `messages`
* **Purpose:** Stores individual chat turns (user prompts and assistant responses).
* **Columns:**
  * `id` (`TEXT PRIMARY KEY`): Unique UUIDv4 identifier.
  * `conversation_id` (`TEXT NOT NULL`): Foreign key referencing `conversations(id)` ON DELETE CASCADE.
  * `role` (`TEXT NOT NULL`): Role constraint `CHECK(role IN ('user', 'assistant', 'system'))`.
  * `content` (`TEXT NOT NULL`): Raw markdown message text.
  * `is_memory_saved` (`INTEGER DEFAULT 0`): Flag `1` if a fact memory was extracted from this message.
  * `created_at` (`INTEGER NOT NULL`): Unix epoch timestamp.

### 2.3 Table: `memories` & `vec_memories`
* **Purpose:** Stores extracted user facts, preferences, and coding guidelines (`Mem0` pattern) with 384-dimensional vector embeddings for cosine similarity search.
* **Columns (`memories`):**
  * `id` (`TEXT PRIMARY KEY`): Unique UUIDv4 identifier.
  * `fact` (`TEXT NOT NULL`): Extracted factual statement (e.g., *"Design uses #121212 Onyx background"*).
  * `category` (`TEXT DEFAULT 'general'`): Category tag (`'design'`, `'architecture'`, `'preference'`).
  * `created_at` (`INTEGER NOT NULL`): Unix epoch timestamp.
* **Columns (`vec_memories` - `sqlite-vec` Virtual Table):**
  * `memory_id` (`TEXT PRIMARY KEY`): References `memories(id)`.
  * `embedding` (`float[384]`): 384-dimensional dense vector representation (computed locally using `all-MiniLM-L6-v2` or Ollama embeddings).

### 2.4 Table: `documents` & `vec_documents`
* **Purpose:** Stores imported local Markdown/Text files and their chunked vector embeddings for offline RAG interrogation.
* **Columns (`documents`):**
  * `id` (`TEXT PRIMARY KEY`): Unique UUIDv4 identifier.
  * `filename` (`TEXT NOT NULL`): Original file name (e.g., `project_spec.md`).
  * `file_path` (`TEXT NOT NULL`): Local sandbox file path.
  * `file_size` (`INTEGER NOT NULL`): Size in bytes.
  * `chunk_count` (`INTEGER NOT NULL`): Total text chunks indexed.
  * `created_at` (`INTEGER NOT NULL`): Unix epoch timestamp.
* **Columns (`vec_documents` - `sqlite-vec` Virtual Table):**
  * `chunk_id` (`TEXT PRIMARY KEY`): Unique chunk UUID.
  * `document_id` (`TEXT NOT NULL`): Foreign key referencing `documents(id)` ON DELETE CASCADE.
  * `chunk_text` (`TEXT NOT NULL`): 500-character text segment.
  * `chunk_index` (`INTEGER NOT NULL`): Segment sequence index (0, 1, 2...).
  * `embedding` (`float[384]`): 384-dimensional vector embedding.

### 2.5 Table: `tasks`
* **Purpose:** Stores local project action items created manually or generated by AI advice.
* **Columns:**
  * `id` (`TEXT PRIMARY KEY`): Unique UUIDv4 identifier.
  * `title` (`TEXT NOT NULL`): Task summary.
  * `description` (`TEXT`): Detailed notes or checklist steps.
  * `status` (`TEXT CHECK(status IN ('todo', 'in_progress', 'completed')) DEFAULT 'todo'`): Task state.
  * `priority` (`TEXT CHECK(priority IN ('low', 'medium', 'high')) DEFAULT 'medium'`): Priority level.
  * `due_date` (`INTEGER`): Optional due date timestamp.
  * `created_at` (`INTEGER NOT NULL`): Unix epoch timestamp.

## 3. Indexes & Constraints

To ensure fast performance on mobile devices and desktop, the following indexes are created:

```sql
-- Foreign Key Enforcement
PRAGMA foreign_keys = ON;

-- Message Lookup Index
CREATE INDEX IF NOT EXISTS idx_messages_conversation_id ON messages(conversation_id);

-- Task Status & Priority Indexes
CREATE INDEX IF NOT EXISTS idx_tasks_status ON tasks(status);
CREATE INDEX IF NOT EXISTS idx_tasks_priority ON tasks(priority);

-- Memory Category Index
CREATE INDEX IF NOT EXISTS idx_memories_category ON memories(category);
```

## 4. Security, Access Rules, and Privacy Rules

### 4.1 Access Boundaries
* **Device Sandbox:** The database file (`ollivo.db`) is stored exclusively in the OS application sandbox:
  * macOS: `~/Library/Application Support/com.ollivo.app/ollivo.db`
  * iOS: `<App Sandbox>/Library/Application Support/ollivo.db`
  * Android: `/data/data/com.ollivo.app/databases/ollivo.db`
  * Web: Browser `IndexedDB` key-value store.
* **User Ownership:** Implicit local owner access. Zero external auth servers or API keys.

### 4.2 Data That MUST NEVER Be Stored
To guarantee absolute privacy and security, Ollivo enforces strict regex sanitization:
* ❌ Raw passwords, PINs, or credentials.
* ❌ Secret API tokens or SSH private keys.
* ❌ User location telemetry, IP addresses, or device identifiers.
* ❌ External analytics or cloud tracking cookies.

### 4.3 Data Retention & Deletion Requirements
* **Single Memory Deletion ("Forget Fact"):** Instantly deletes the target row from `memories` and deletes its corresponding embedding from `vec_memories`.
* **One-Click Factory Reset ("Clear All Memory"):** Executes `DROP TABLE` and re-initializes empty SQLite schemas, permanently purging all local data.

## 5. Migration & Rollback Strategy

* **Version Management:** Managed via SQLite `PRAGMA user_version`.
* **Migration Helper:** All schema changes are non-destructive using guarded `CREATE TABLE IF NOT EXISTS` and `ALTER TABLE ADD COLUMN`.

```dart
// Migration Engine Example in DatabaseService
Future<void> onUpgrade(Database db, int oldVersion, int newVersion) async {
  if (oldVersion < 2) {
    // Non-destructive upgrade example for future schema iterations
    await db.execute('ALTER TABLE tasks ADD COLUMN category TEXT DEFAULT "general"');
  }
}
```

## 6. Optional Supabase / PostgreSQL Reference Schema (For Future Cloud Deployment)

If Ollivo ever adds an opt-in cloud sync extension using Supabase/PostgreSQL in the future, the exact same entities translate to PostgreSQL DDL with Row Level Security (RLS) enabled:

```sql
-- PostgreSQL Supabase RLS Example (Opt-In Cloud Sync Only)
CREATE TABLE IF NOT EXISTS public.memories (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
    fact TEXT NOT NULL,
    category TEXT DEFAULT 'general',
    created_at TIMESTAMPTZ DEFAULT now()
);

ALTER TABLE public.memories ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users access own memories"
    ON public.memories
    FOR ALL
    USING (auth.uid() = user_id);
```
